First release.

- The edit model: thirteen operations (`rotate`, `flip`, `crop`, `straighten`, `resize`, `adjust`, `filter`, `blur`, `sharpen`, `pixelate`, `stroke`, `shape`, `text`) as plain JSON, with the size they leave, no-op detection and validation of untrusted data.
- A Canvas 2D renderer that never changes its source and takes its canvases from a factory (page, worker or server).
- Pixel functions on plain RGBA bytes: colour matrices for tone and looks, blur, mosaic, sharpen.
- Export to PNG, JPEG or WebP with quality, including plain format conversion, and a check for the formats the browser can really write.
- Interaction geometry: crop handles with locked ratios, zoom and pan, screen-to-image coordinates, undo / redo.

Install:

```bash
bun add https://github.com/seiunx-dev/image-edit-kit/releases/download/v0.1.0/image-edit-kit-0.1.0.tgz
```
